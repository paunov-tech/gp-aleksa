# 05 — Lažni prijatelji slovenački ↔ srpski u pravu

Reči koje liče na srpske, a u slovenačkom pravu znače nešto drugo (ili uže / šire). Članovi zakona su provereni u prečišćenim tekstovima sa pisrs.si (`izvori/zakoni/`, pristup 13. 11. 2026.). Tumačenje razlike prema srpskom je moje (pouzdanost C) — služi učenju jezika, ne kao pravni izvor.

## A. Najopasniji (menjaju smisao pitanja)

| Slovenački | Liči na (SR) | Stvarno znači | Objašnjenje i izvor |
|---|---|---|---|
| **družba** | družba (društvo ljudi), druženje | **privredno društvo** (kompanija) | „Gospodarska družba je pravna oseba, ki na trgu samostojno opravlja pridobitno dejavnost" (ZGD-1, 3. člen). „Društvo" na slovenačkom = udruženje građana, NE firma. |
| **društvo** | (privredno) društvo | **udruženje** (neprofitno) | Obrnuto od srpskog! SR „privredno društvo" = SL „gospodarska družba". |
| **družbenik** | drug, saputnik | **član društva / ortak** (u d.o.o., d.n.o., k.d.) | Vlasnik udela. U d.d. se zove **delničar**. |
| **podjetje** | preduzeće | **preduzeće kao imovinska celina / delatnost**, kolokvijalno firma | Pravni subjekt je *družba* ili *podjetnik*, ne „podjetje". |
| **podjetnik** | preduzetnik | **preduzetnik (s.p.)** — fizičko lice | Tačno liči, ali pazi: *samostojni podjetnik posameznik (s.p.)* odgovara celom svojom imovinom. |
| **firma** | firma (= kompanija) | **samo IME** pod kojim društvo posluje | „Firma je ime, s katerim družba posluje" (ZGD-1, 12. člen). Tvrdnja „firma je pravna oseba" je NETAČNA. |
| **upnik** | „upnik"?? (nema) / mešanje sa „dužnik" | **poverilac** | Onaj kome se duguje. Suprotno: **dolžnik** = dužnik. |
| **terjatev** | „teranje" | **potraživanje** | Pravo poverioca da zahteva ispunjenje. *Terjati* = potraživati. |
| **obresti** | „obrasti" | **kamata** | *Zamudne obresti* = zatezna kamata; 8 % godišnje ako poseban zakon ne određuje drugačije (OZ, 378. člen). *Obrestna mera* = kamatna stopa. |
| **zamuda** | zamka? | **docnja** (kašnjenje sa ispunjenjem) | „Dolžnik pride v zamudo, če ne izpolni obveznosti v roku" (OZ, 299. člen). Postoji i *zamuda upnika* (docnja poverioca). |
| **odstop** | odstupanje | DVA značenja: **(1) odstop terjatve = cesija** (ustupanje potraživanja, OZ, 417. člen); **(2) odstop od pogodbe = raskid / odustanak od ugovora** | U pitanju uvek pogledaj šta sledi: *terjatve* ili *od pogodbe*. |
| **posest** | posed (= imanje, zemlja) | **državina** — faktička vlast na stvari | „Posest je neposredna dejanska oblast nad stvarjo" (SPZ, 24. člen). Posest ≠ svojina. |
| **lastnina / lastninska pravica** | „vlastnina" | **svojina / pravo svojine** | „pravica imeti stvar v posesti, jo uporabljati in uživati … ter z njo razpolagati" (SPZ, 37. člen). *Lastnik* = vlasnik. |
| **najem / zakup** | najam | **zakup** | OZ koristi oba kao sinonime: „zakupna (najemna) pogodba" (OZ, 587. člen). *Najemnina* = zakupnina. |
| **zastaranje** | zastarelost | **zastarelost potraživanja** | Prestaje pravo da se ZAHTEVA ispunjenje, ne sama obaveza (OZ, 335. člen); opšti rok 5 godina (OZ, 346. člen). Sud na zastarelost NE pazi po službenoj dužnosti. |
| **pogodba** | pogodba (cenkanje) | **ugovor** | *Pogodbena stranka* = ugovorna strana. *Pogodbena kazen* = ugovorna kazna (OZ, 247. člen). |
| **obveznost** | obveznost (opšta obaveza) | **obligacija / obaveza** iz obligacionog odnosa | *Obligacijski zakonik (OZ)* = zakon o obligacionim odnosima. |
| **škoda / odškodnina** | šteta (žalost: „šteta") | **šteta / naknada štete** | „Kdor povzroči drugemu škodo, jo je dolžan povrniti" (OZ, 131. člen). *Odškodninska odgovornost* = odgovornost za štetu. |
| **krivda** | krivda (nepravda) | **krivica** (vinost: namera ili nepažnja) | *Malomarnost* = nepažnja (nehat). |
| **ničnost** | ništavost | **ništavost** (apsolutna nevažnost) | Pogodba protivna ustavu, prinudnim propisima ili moralu je nična (OZ, 86. člen). |
| **izpodbojnost** | „ispod boja" | **rušljivost** (relativna nevažnost) | Pogodba je izpodbojna zbog ograničene poslovne sposobnosti ili mana volje (OZ, 94. člen). Važi dok se ne poništi. |
| **razveza / razdor** | razvod | **raskid ugovora** | *Razvezana po samem zakonu* = raskinut po samom zakonu (OZ, 104. člen). |
| **poroštvo / porok** | „porok" (mana) | **jemstvo / jemac** | „porok … se zavezuje, da bo izpolnil … obveznost dolžnika, če ta tega ne bi storil" (OZ, 1012. člen). |
| **zastava / zastavna pravica** | zastava (barjak) | **zaloga / založno pravo** | SPZ, 128. člen. *Hipoteka* = založno pravo na nepokretnosti. |
| **ara** | — | **kapara** | OZ, 64. člen. |
| **pobot** | „pobuna" | **prebijanje (kompenzacija)** | OZ, 311. člen. |
| **prevzem dolga** | preuzimanje | **preuzimanje duga** | Traži pristanak poverioca (OZ, 427. člen). |
| **naročilo / pogodba o naročilu** | narudžbina | **nalog (mandat)** | OZ, 766. člen. *Naročnik* kod podjemne pogodbe = naručilac. |
| **podjemna pogodba** | „poduzetnička" | **ugovor o delu** | OZ, 619. člen. *Podjemnik* = poslenik (izvođač). NE mešati sa *podjetnik* (preduzetnik)! |
| **posojilo** | posuda | **zajam** | OZ, 569. člen. (*Posodba* = posluga, besplatna upotreba stvari.) |
| **vrednostni papir** | „vredan papir" | **hartija od vrednosti** | *Menica* = menica, *ček*, *delnica* = akcija, *obveznica* = obveznica. |
| **delnica / delničar** | deonica (deo puta) | **akcija / akcionar** | *Delniška družba (d.d.)* = akcionarsko društvo. |
| **poslovni delež** | — | **udeo** u d.o.o. | Ne „akcija". |
| **osnovni vložek** | uložak | **osnovni ulog** | U d.o.o. najmanje 50 EUR; osnovni kapital najmanje 7.500 EUR (ZGD-1, 475. člen). |
| **skupščina** | skupština (parlament) | **skupština društva** (organ d.d. / d.o.o.) | Parlament je *Državni zbor*. |
| **uprava** | uprava (administracija) | **uprava = organ vođenja d.d.** (kao izvršni odbor) | *Nadzorni svet* = nadzorni odbor. |
| **poslovodja** | poslovođa (šef smene) | **direktor d.o.o.** (zakonski zastupnik) | *Poslovodstvo* = organ vođenja. |
| **zastopnik / zastopanje** | zastupnik | **zastupnik** | Tačno, ali pazi: *zakoniti zastopnik* = zakonski zastupnik; *pooblaščenec* = punomoćnik; *prokurist* (ZGD-1, 33. člen). |
| **sodišče / sodnik / sodba** | — | **sud / sudija / presuda** | *Okrajno* = osnovni niži, *okrožno* = viši prvostepeni, *višje* = apelacioni, *Vrhovno*. *Sklep* = rešenje. |
| **tožba / tožnik / toženec** | tužba | **tužba / tužilac / tuženi** | *Tožilec* = javni tužilac (krivično)! *Tožnik* = tužilac u parnici. |
| **pravdni postopek** | „pravda" | **parnični postupak** | ZPP. |
| **stečaj** | stečaj | **stečaj** | Tačno. *Prisilna poravnava* = prinudno poravnanje. *Likvidacija* = likvidacija. |
| **izbris** | brisanje | **brisanje iz registra** | Društvo prestaje brisanjem iz registra. |
| **predpis** | propis | **propis** | *Zakon, uredba, pravilnik, odlok*. *Uredba* (EU) = uredba; *direktiva*. |
| **veljavnost / uporaba** | — | **važenje / primena** | Propis može da *velja*, a da se još ne *uporablja*. |
| **pravna oseba / fizična oseba** | osoba | **pravno lice / fizičko lice** | *Pravna sposobnost* / *poslovna sposobnost*. |
| **premoženje** | „premoženje" | **imovina** | „z vsem svojim premoženjem" = celom svojom imovinom (ZGD-1, 76. člen). |
| **dobiček / izguba** | dobitak / gubitak | **dobit / gubitak** | *Pridobitna dejavnost* = delatnost radi sticanja dobiti (ZGD-1, 3. člen). |
| **stvar** | stvar | **stvar** (telesni predmet) | „Stvar je samostojen telesni predmet, ki ga človek lahko obvladuje" (SPZ, 15. člen). *Premičnina / nepremičnina* = pokretnost / nepokretnost. |

## C. Parovi koje test voli da zameni

- **ničnost** (ništavost; od početka, sud pazi sam) ↔ **izpodbojnost** (rušljivost; važi dok se ne poništi).
- **posest** (državina, faktičko) ↔ **lastninska pravica** (svojina, pravo).
- **odstop terjatve** (menja se poverilac; cesija) ↔ **prevzem dolga** (menja se dužnik; treba pristanak poverioca).
- **poroštvo** (lično obezbeđenje) ↔ **zastavna pravica** (stvarno obezbeđenje).
- **ara** (znak da je ugovor zaključen) ↔ **pogodbena kazen** (za neispunjenje / docnju) ↔ **odstopnina** (odustanica: cena za odustanak).
- **družbenik** (d.o.o., d.n.o., k.d.) ↔ **delničar** (d.d.).
- **komplementar** (odgovara celom imovinom) ↔ **komanditist** (ne odgovara za obaveze društva) — ZGD-1, 135. člen.
- **osebne družbe** (d.n.o., k.d.) ↔ **kapitalske družbe** (d.o.o., d.d., k.d.d., SE) — ZGD-1, 3. člen.
- **osnovni kapital**: d.o.o. najmanje **7.500 EUR** (ZGD-1, 475. člen) ↔ d.d. najmanje **25.000 EUR** (ZGD-1, 171. člen).
- **podjemnik** (izvođač po ugovoru o delu) ↔ **podjetnik** (preduzetnik).
- **tožnik** (tužilac u parnici) ↔ **tožilec** (javni tužilac).
- **posojilo** (zajam) ↔ **posodba** (posluga) ↔ **najem / zakup** (zakup uz naknadu).
